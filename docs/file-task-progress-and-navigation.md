# 本地文件任务的进度与浏览

存档备份、创建环境还原点、克隆版本、恢复世界和环境恢复通过实际读取、压缩、校验与复制的字节上报分段进度；多世界备份按世界分段。克隆覆盖来源哈希、复制与副本校验、最终来源复核，提交前保留原有一致性检查和临时目录清理。准备、写入与最终提交使用不同进度区间，原生加载器仅在负载成功结束后显示完成。取消不依赖显示进度：`LoaderFileOperation` 仍等待流、临时文件、finally 与回滚结束，再释放版本占用。

`McInstanceLock.IsLocked` 继续表示版本被文件任务占用，用于拒绝启动和冲突写入；`BlocksNavigation` 单独决定是否允许返回版本界面。创建快照、克隆来源允许浏览概览、Mod 和资源列表，版本设置与组件修改入口暂时受限。Mod 写入及资源修改也保留占用检查。恢复世界、环境恢复、迁移测试环境与包含未完成事务恢复的操作继续阻止进入版本设置。

从任务管理返回时，保留版本侧栏中进入任务前的子页，例如还原点、克隆或存档。主窗口和侧栏统一同步页面编号、选中项与右侧内容；快照期间只有受限的编辑页回退到概览，回退时同步选中概览。被拒绝的侧栏点击恢复原选中项，避免显示内容与选中项不一致。

备份目录、还原点清单只在完整写入后原子发布。读取已发布列表不再持有覆盖整个压缩或复制过程的操作锁，避免返回存档、还原点页面时等待后台任务。写入之间仍使用原有串行保护及跨进程锁；读取忽略并发清理后已被移走的记录，不将部分写入数据作为可恢复点。

存档页操作后的刷新在后台合并执行，不再重新显示整页加载层。目录、`level.dat` 和图标的文件状态未变化时，复用存档元数据、图标及原生行；备份清单和压缩包未变化时，复用经过验证的显示摘要，并保留未变化分组的展开状态和选择。删除、移动、修改对应文件会使相应缓存失效；手动刷新会清空缓存重新读取。离开页面或切换实例时取消旧刷新，丢弃过期结果。

显示摘要不参与恢复和删除的授权或内容校验；实际操作仍重新读取当前清单，并保留原有完整备份校验、回滚和路径保护。

## 备份与还原点的存储位置

在“设置 → 其他 → 世界备份与环境还原点”的路径输入框右侧点击“选择”，通过 PCL 现有文件夹窗口选择一个空文件夹，并在确认窗口中确认迁移。世界备份与还原点共同使用所选目录，分别保存在 `world-backups`、`environment-history` 子目录中。未更改时继续读取原有 `%LOCALAPPDATA%\PCL Living Fork\GameData`，兼容旧备份。

迁移作为原生文件任务在后台运行，期间持有两个备份引擎的操作锁；复制、哈希校验和源目录复核完成后才原子保存位置配置。失败或在提交前取消时保留原位置，已有目标文件不会被覆盖。新位置提交后仅清理内容仍与迁移快照一致的旧文件，未能清理的文件会保留并提示。个人方案、账号和游戏目录不随这两个备份目录移动。

位置配置保存在当前用户的独立注册表节点 `HKEY_CURRENT_USER\Software\PCL Living Fork` 中，值名为 `BackupStorageRoot`，类型为 `REG_SZ`。同一 Windows 用户下的新版 PCLLF 共用该值，不写入官方 `Software\PCL` 节点，也不随普通设置的导入或重置改变。已使用开发测试包 JSON 配置的用户，首次读取会自动导入 `backup-storage.json` 中的位置；注册表值优先，之后不再回写 JSON。自定义位置不可用时不自动改回 C 盘；请先连接原存储设备。变更位置时应等待当前游戏和文件任务结束。

该独立节点同时接收 LF 专用设置的一次性兼容迁移，包括 `LaunchPersonalOptions*`、`LaunchRecentWorlds`、`UiLaunchMoreSettings`、LF 更新忽略标记及 `_LF` 后缀的 13 项微软账号记录。精确范围、事务校验与回滚规则见[微软登录存储隔离](microsoft-account-storage.md)。`Identify`、通用兼容偏好、未加后缀的官方账号值与未确认来源的历史凭据保留原有规则。

`Test-BackupTaskProgress.ps1` 使用独立目录和真实 UI 任务负载，验证连续进度、两种恢复、快照期间浏览、读写互斥、列表读取与取消清理。`Test-CloneTaskProgress.ps1` 验证原生克隆任务、单个大文件复制时的进度、各阶段取消和提交边界；`Test-FileTaskNavigation.ps1` 重放原生返回操作并检查选中项与页面内容。`Test-WorldBackups.ps1`、`Test-EnvironmentHistory.ps1`、`Test-ReviewFixes.ps1` 验证存档、共享文件、校验、中断恢复与回滚。

备份与环境还原点确认后永久删除，不再移动到 `deleted`。批量操作在删除前检查全部编号和记录；环境还原点只回收未被其余还原点引用的数据。恢复期间禁止删除，存档恢复事务引用的目标及恢复前备份也受到保护。升级后后台清理旧删除目录，失败时保留未清理内容待下次启动重试；此过程不删除当前存档或游戏环境文件。

游戏退出监控独立检查真实进程状态，不依赖最后一条日志或 EOF。关闭日志、启动加载器取消及主动结束请求均不代表进程已经退出；确认退出后，存档会话、个人设置和 Quick Play 收尾各执行一次。退出前公布的关闭状态不会丢弃仍存活的进程。启动拦截分别提示存档、测试副本、环境还原点、整合包或文件写入任务，并记录原因；退出备份会话记录开始与完成，方便区分实际后台备份与未释放的版本保护。游戏结束不会绕过仍在执行的文件事务或提前释放其版本预留。
