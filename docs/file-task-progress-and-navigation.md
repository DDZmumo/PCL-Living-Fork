# 本地文件任务的进度与浏览

存档备份、创建环境还原点、克隆版本、恢复世界和环境恢复通过实际读取、压缩、校验与复制的字节上报分段进度；多世界备份按世界分段。克隆覆盖来源哈希、复制与副本校验、最终来源复核，提交前保留原有一致性检查和临时目录清理。准备、写入与最终提交使用不同进度区间，原生加载器仅在负载成功结束后显示完成。取消不依赖显示进度：`LoaderFileOperation` 仍等待流、临时文件、finally 与回滚结束，再释放版本占用。

`McInstanceLock.IsLocked` 继续表示版本被文件任务占用，用于拒绝启动和冲突写入；`BlocksNavigation` 单独决定是否允许返回版本界面。创建快照、克隆来源允许浏览概览、Mod 和资源列表，版本设置与组件修改入口暂时受限。Mod 写入及资源修改也保留占用检查。恢复世界、环境恢复、迁移测试环境与包含未完成事务恢复的操作继续阻止进入版本设置。

从任务管理返回时，保留版本侧栏中进入任务前的子页，例如还原点、克隆或存档。主窗口和侧栏统一同步页面编号、选中项与右侧内容；快照期间只有受限的编辑页回退到概览，回退时同步选中概览。被拒绝的侧栏点击恢复原选中项，避免显示内容与选中项不一致。

备份目录、还原点清单只在完整写入后原子发布。读取已发布列表不再持有覆盖整个压缩或复制过程的操作锁，避免返回存档、还原点页面时等待后台任务。写入之间仍使用原有串行保护及跨进程锁；读取忽略并发清理后已被移走的记录，不将部分写入数据作为可恢复点。

存档页操作后的刷新在后台合并执行，不再重新显示整页加载层。目录、`level.dat` 和图标的文件状态未变化时，复用存档元数据、图标及原生行；备份清单和压缩包未变化时，复用经过验证的显示摘要，并保留未变化分组的展开状态和选择。删除、移动、修改对应文件会使相应缓存失效；手动刷新会清空缓存重新读取。离开页面或切换实例时取消旧刷新，丢弃过期结果。

显示摘要不参与恢复和删除的授权或内容校验；实际操作仍重新读取当前清单，并保留原有完整备份校验、回滚和路径保护。

`Test-BackupTaskProgress.ps1` 使用独立目录和真实 UI 任务负载，验证连续进度、两种恢复、快照期间浏览、读写互斥、列表读取与取消清理。`Test-CloneTaskProgress.ps1` 验证原生克隆任务、单个大文件复制时的进度、各阶段取消和提交边界；`Test-FileTaskNavigation.ps1` 重放原生返回操作并检查选中项与页面内容。`Test-WorldBackups.ps1`、`Test-EnvironmentHistory.ps1`、`Test-ReviewFixes.ps1` 验证存档、共享文件、校验、中断恢复与回滚。
